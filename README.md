# Reinforcement Learning

Let's learn RL!

## Installation

This project uses [uv](https://docs.astral.sh/uv/) to manage Python and its dependencies.

```bash
# Install uv
curl -LsSf https://astral.sh/uv/install.sh | sh

# Install dependencies
uv sync
```
